# OmniMind

A modular personal operating system for planning, knowledge, learning and focused work.

Targets three platforms from one shared TypeScript codebase: Web, Android and iOS.

- See `docs/roadmap.md` for the approved ten-phase roadmap.
- See `docs/standards/README.md` for the engineering, security and quality policy.
- See `docs/standards/COMPLIANCE-MATRIX.md` for control status and verification evidence.
